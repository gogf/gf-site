## GoFrame v2.10.5 Released: Go 1.25 and OpenTelemetry v1.45 Upgrades, a slog Handler, and Fixes Across ghttp, gdb, gconv and More

`GoFrame v2.10.5` has been released. This version upgrades `OpenTelemetry` to `v1.45.0` and `Go` to `1.25`, adds a `slog` handler that forwards to `glog`, and fixes issues across `net/ghttp`, `database/gdb`, `util/gconv`, `os/glog`, `text/gstr`, `os/gtime`, `os/gcache`, `os/gsession`, `container/gtree`, and more. It also brings batched `ORM` relation scans and `gconv` performance improvements.

Full changelog: [https://github.com/gogf/gf/releases/tag/v2.10.5](https://github.com/gogf/gf/releases/tag/v2.10.5)

Code diff: [https://github.com/gogf/gf/compare/v2.10.4...v2.10.5](https://github.com/gogf/gf/compare/v2.10.4...v2.10.5)

## New Features

### Dependency upgrades

- Upgrade `OpenTelemetry` to `v1.45.0` and `Go` to `1.25`. [#4863](https://github.com/gogf/gf/pull/4863) (@houseme)

### Logging `os/glog`

- Added a `slog handler` that forwards standard-library `slog` logs to `glog`. [#4986](https://github.com/gogf/gf/pull/4986) (@LanceAdd)

## Bug Fixes

### HTTP server `net/ghttp`

- Log erroneous request duration in seconds, consistent with the access log. [#4933](https://github.com/gogf/gf/pull/4933) (@LuisFigueroaG)
- Preserve body values in filtered query maps. [#4909](https://github.com/gogf/gf/pull/4909) (@allenflux)
- Skip `gzip` for already committed responses. [#4960](https://github.com/gogf/gf/pull/4960) (@LanceAdd)
- Correct file download response headers. [#4988](https://github.com/gogf/gf/pull/4988) (@LanceAdd)

### ORM `database/gdb`

- Keep the `MySQL` `time_zone` link parameter from overriding `Timezone`. [#4937](https://github.com/gogf/gf/pull/4937) (@ShryukGrandhi)
- Support `FieldsEx` and `FieldsExPrefix` on join statements. [#4939](https://github.com/gogf/gf/pull/4939) (@ShryukGrandhi)
- Scan records into map slices instead of empty maps. [#4955](https://github.com/gogf/gf/pull/4955) (@LuisFigueroaG)
- Disable the model cache for queries running in a context transaction. [#4964](https://github.com/gogf/gf/pull/4964) (@ShryukGrandhi)

### System `os`

- `os`: stop accumulating `inotify` watches. [#4944](https://github.com/gogf/gf/pull/4944) (@LanceAdd)
- `os/gres`: use slash separators for virtual directory entries in pack. [#4936](https://github.com/gogf/gf/pull/4936) (@ShryukGrandhi)
- `os/gproc`: skip Unix-only pid mapping folders on Windows. [#4956](https://github.com/gogf/gf/pull/4956) (@b84330808)
- `os/gfile`: keep `MatchGlob` globstar matching separator-aware on Windows. [#4961](https://github.com/gogf/gf/pull/4961) (@b84330808)
- `os/gcache`: keep missed lookups out of the memory `LRU`. [#4968](https://github.com/gogf/gf/pull/4968) (@waw666waw666)
- `os/gsession`: refresh the `TTL` of `RedisHashTable` sessions that are only read. [#4975](https://github.com/gogf/gf/pull/4975) (@waw666waw666)
- `os/gtime`: accept fractions and a plus sign on days in `ParseDuration`. [#4974](https://github.com/gogf/gf/pull/4974) (@Kernel-Hunter)

### CLI `cmd/gf`

- `gen dao`: keep the `orm` tag in the do struct when `removeFieldPrefix` is set. [#4952](https://github.com/gogf/gf/pull/4952) (@LuisFigueroaG)
- `gen ctrl`: keep import aliases when parsing existing controllers. [#4940](https://github.com/gogf/gf/pull/4940) (@ShryukGrandhi); find the api import by path. [#4957](https://github.com/gogf/gf/pull/4957) (@nk-batman21)

### Other modules

- `contrib/drivers/sqlite`: upgrade `modernc.org/sqlite` to `v1.39.0` for `loong64` support. [#4950](https://github.com/gogf/gf/pull/4950) (@lingcoder)
- `contrib/drivers/gaussdb`: cast the `MERGE` placeholders of `Save` and `Replace` to the column type. [#4969](https://github.com/gogf/gf/pull/4969) (@lingcoder)
- `util/gconv`: convert slices wrapped by `gvar.Var` into slice fields. [#4943](https://github.com/gogf/gf/pull/4943) (@nk-batman21)
- `os/glog`: print fatal logs synchronously on async loggers. [#4930](https://github.com/gogf/gf/pull/4930) (@LuisFigueroaG)
- `database/gredis`: accept score and lex bounds for `ZRange` start and stop. [#4959](https://github.com/gogf/gf/pull/4959) (@ShryukGrandhi)
- `container/gtree`: fix a deadlock and ignored stop signal in `Iterator*From`. [#4966](https://github.com/gogf/gf/pull/4966) (@waw666waw666)
- `text/gstr`: count a two-byte character as one rune in `PosRune`, `PosIRune`, `PosRRune` and `PosRIRune`. [#4973](https://github.com/gogf/gf/pull/4973) (@Kernel-Hunter); stop `Soundex` from writing `"0"` for vowels. [#4971](https://github.com/gogf/gf/pull/4971) (@Kernel-Hunter); return from `ReplaceI` when search is empty. [#4972](https://github.com/gogf/gf/pull/4972) (@Kernel-Hunter)

## Upgrade Guide

```bash
go get -u github.com/gogf/gf/v2@v2.10.5
```

This release raises the minimum `Go` version to `1.25` and upgrades `OpenTelemetry`; please upgrade the `CLI` to the corresponding version as well. If you use any of the following features, it is recommended to verify them first:

- `slog` forwarding to `glog`
- `ORM` batched relation scans, `FieldsEx` / `FieldsExPrefix` on joins, and `gredis` range queries
- Repeated query filtering, file download response headers, and `gzip` behavior
- `gstr`, `gtime`, `gtree`, `gcache`, and `gsession` logic
- `SQLite` on `loong64`

Questions and discussion: [https://github.com/gogf/gf/issues](https://github.com/gogf/gf/issues)
