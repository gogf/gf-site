## GoFrame v2.10.6 Released: a Request Body Auto-Decoding Switch and grpcx Server Timeouts, Hardened Extraction and Static File Serving, and Fixes Across gdb, gtime, gcompress and More

`GoFrame v2.10.6` has been released. This version adds the `AutoDecodingBodyDisabled` option for `ghttp.Server` and a server-side timeout for unary requests in `contrib/rpc/grpcx`. It also hardens `zip` extraction against path traversal, anchors static file reads in `net/ghttp` and path searches in `os/gspath` to their roots, and fixes partition queries in `database/gdb`, DST zone offsets and timestamp overflow in `os/gtime`, and more. A large batch of unit tests and a round of modernization refactors are included as well.

Full changelog: [https://github.com/gogf/gf/releases/tag/v2.10.6](https://github.com/gogf/gf/releases/tag/v2.10.6)

Code diff: [https://github.com/gogf/gf/compare/v2.10.5...v2.10.6](https://github.com/gogf/gf/compare/v2.10.5...v2.10.6)

## New Features

### HTTP server `net/ghttp`

- Added the `AutoDecodingBodyDisabled` option to disable automatic request body decoding on demand. [#4197](https://github.com/gogf/gf/pull/4197) (@gqcn)

### RPC server `contrib/rpc/grpcx`

- Added server-side timeouts for unary requests. [#4996](https://github.com/gogf/gf/pull/4996) (@officialasishkumar)

## Bug Fixes

### HTTP server `net/ghttp`

- Anchor static file reads to the search root to prevent out-of-root reads. (Security) [#4985](https://github.com/gogf/gf/pull/4985) (@LanceAdd)
- Escape links in static directory listings to prevent page injection. (Security) [#5009](https://github.com/gogf/gf/pull/5009) (@LanceAdd)
- Parse the host and port of listen addresses with `net.SplitHostPort`. [#5007](https://github.com/gogf/gf/pull/5007) (@LanceAdd)

### HTTP client `net/gclient`

- Keep query parameters before the URL fragment. [#5025](https://github.com/gogf/gf/pull/5025) (@LanceAdd)

### Compression `encoding/gcompress`

- Prevent zip path traversal on extraction. (Security) [#5010](https://github.com/gogf/gf/pull/5010) (@LanceAdd)
- Close decompression readers so file handles are not leaked. [#5013](https://github.com/gogf/gf/pull/5013) (@LanceAdd)

### JSON `encoding/gjson`

- Reject negative array indexes without partial writes. [#5012](https://github.com/gogf/gf/pull/5012) (@LanceAdd)

### Other encoding components

- `encoding/gini`: parse the last configuration line when it has no trailing newline. [#5014](https://github.com/gogf/gf/pull/5014) (@LanceAdd)
- `encoding/gbinary`: keep `EncodeBitsToBytes` from mutating the caller slice. [#5011](https://github.com/gogf/gf/pull/5011) (@LanceAdd)
- `encoding/gurl`: keep literal plus signs in `RawDecode`. [#5016](https://github.com/gogf/gf/pull/5016) (@LanceAdd)

### ORM `database/gdb`

- Emit the `PARTITION` clause set by `Model.Partition()` in `SELECT` queries. [#4976](https://github.com/gogf/gf/pull/4976) (@lingcoder)

### Time `os/gtime`

- `StrToTime` no longer loses the zone offset across DST. [#4995](https://github.com/gogf/gf/pull/4995) (@ruziba3vich)
- Fix `Timestamp` overflow outside the `UnixNano` range. [#4989](https://github.com/gogf/gf/pull/4989) (@ruziba3vich)
- Use the Unix time helpers together with `os/gcron` and `internal/tracing`. [#5005](https://github.com/gogf/gf/pull/5005) (@LanceAdd)

### Cron `os/gcron`

- Reject pattern intervals below `1` instead of looping forever. [#5019](https://github.com/gogf/gf/pull/5019) (@ruziba3vich)

### Files and paths `os/gfile`, `os/gspath`

- `os/gfile`: `ReadLines` no longer drops over-long lines. [#5024](https://github.com/gogf/gf/pull/5024) (@LanceAdd)
- `os/gspath`: keep search results inside the searching root. (Security) [#5023](https://github.com/gogf/gf/pull/5023) (@LanceAdd)

### Network helpers `net/gipv4`, `net/gtrace`

- `net/gipv4`: detect intranet addresses with `netip`. [#5006](https://github.com/gogf/gf/pull/5006) (@LanceAdd)
- `net/gipv4`: fix the `panic` of `Ip2long` on `IPv6` addresses. [#4990](https://github.com/gogf/gf/pull/4990) (@ruziba3vich)
- `net/gtrace`: detect `gzip` content encoding case-insensitively. [#5026](https://github.com/gogf/gf/pull/5026) (@LanceAdd)

### Utilities `util/gutil`

- Compare typed values instead of subtracting them. [#5004](https://github.com/gogf/gf/pull/5004) (@LanceAdd)
- Fix the wrong sign of integer comparators on overflow. [#4994](https://github.com/gogf/gf/pull/4994) (@ruziba3vich)

### Strings `text/gstr`

- Do not append the suffix twice when the string length equals the limit. [#4993](https://github.com/gogf/gf/pull/4993) (@ruziba3vich)
- `TrimLeftStr` and `TrimRightStr` no longer loop forever on an empty cut. [#4991](https://github.com/gogf/gf/pull/4991) (@ruziba3vich)
- Fix the result of `Str` when the needle is longer than one byte. [#4992](https://github.com/gogf/gf/pull/4992) (@ruziba3vich)

### Array `container/garray`

- `Range` supports the documented negative end index. [#5020](https://github.com/gogf/gf/pull/5020) (@ruziba3vich)

### CLI `cmd/gf`

- `gen ctrl` detects parameterized `NewV1` constructors to avoid duplicate `ControllerV1` generation. [#4980](https://github.com/gogf/gf/pull/4980) (@Lizjunn)
- Restore the `imports.Process` based `GoFmt` handling. [#5045](https://github.com/gogf/gf/pull/5045) (@hailaz)

### Contrib `contrib/rpc/grpcx`

- Protect the listener with a mutex to fix a data race. [#5046](https://github.com/gogf/gf/pull/5046) (@hailaz)
- Do not exit the process when `Serve` returns `grpc.ErrServerStopped`. [#5049](https://github.com/gogf/gf/pull/5049) (@LanceAdd)

## Upgrade Guide

```bash
go get -v github.com/gogf/gf/v2@v2.10.6
```

This is a patch release and remains backward compatible. If you use the following capabilities, we recommend verifying them first:

- Static file serving and request body auto-decoding behavior in `ghttp`
- Zip extraction path validation in `gcompress`
- Partitioned table queries in `gdb`
- Time zone and timestamp conversion in `gtime`
- String truncation and trimming in `garray.Range` and `gstr`

Issues and discussions: [https://github.com/gogf/gf/issues](https://github.com/gogf/gf/issues)

`Star` the project, open an `Issue` or send a `PR`. `GoFrame` makes Go development simpler.
