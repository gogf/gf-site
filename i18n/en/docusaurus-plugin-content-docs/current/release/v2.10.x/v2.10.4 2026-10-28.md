## GoFrame v2.10.4 Released: JSON Array Bodies and HTTP Header Constants, with Comprehensive Fixes Across DM, GaussDB, Oracle and MSSQL Drivers

`GoFrame v2.10.4` has been released. This version mainly focuses on bug fixes, with an emphasis on improving compatibility and test coverage across database drivers (Dameng, `GaussDB`, `Oracle`, `MSSQL`, `PgSQL`, `SQLite`, `ClickHouse`, and more). It also adds `JSON` array request body support, `HTTP` header constants, and local coding-agent setup, along with several performance improvements.

Full changelog: [https://github.com/gogf/gf/releases/tag/v2.10.4](https://github.com/gogf/gf/releases/tag/v2.10.4)

Code diff: [https://github.com/gogf/gf/compare/v2.10.3...v2.10.4](https://github.com/gogf/gf/compare/v2.10.3...v2.10.4)

## New Features

### CLI / Agents

- Added the `gf-pr-create` skill and refreshed the root `README`. [#4878](https://github.com/gogf/gf/pull/4878) (@gqcn)
- `agents`: parallelize `gf-pr-review` and honor existing comments. [#4879](https://github.com/gogf/gf/pull/4879) (@gqcn)
- `agents`: extend PR review and drop the `openspec` workflow. [#4911](https://github.com/gogf/gf/pull/4911) (@gqcn)
- `cmd/gf`: added the `gf agents` command for local coding-agent setup. [#4877](https://github.com/gogf/gf/pull/4877) (@gqcn)

### HTTP server `net/ghttp` / OpenAPI `net/goai`

- Support `JSON` array request bodies via the `in:"body"` field tag. [#4898](https://github.com/gogf/gf/pull/4898) (@LanceAdd)
- Added exported `HTTP header` name constants. [#4899](https://github.com/gogf/gf/pull/4899) (@LanceAdd)

## Bug Fixes

### Database drivers `contrib/drivers`

- `clickhouse`: corrected conversion, inserts, and rewriting. [#4916](https://github.com/gogf/gf/pull/4916) (@lingcoder)
- `dm` (Dameng): preserve quoted identifiers. [#4828](https://github.com/gogf/gf/pull/4828) (@yuyinw); ignore column name case when reading metadata columns. [#4875](https://github.com/gogf/gf/pull/4875) (@z312193608); apply timezone to the DM `DSN`. [#4904](https://github.com/gogf/gf/pull/4904) (@014-code); expand test coverage to the `Oracle` baseline with 18 driver fixes. [#4925](https://github.com/gogf/gf/pull/4925) (@lingcoder)
- `gaussdb`: read `int1[]` and `int16[]` arrays back as arrays. [#4896](https://github.com/gogf/gf/pull/4896) (@lingcoder)
- `mssql`: expand test coverage to the `MySQL` baseline with 16 driver fixes. [#4924](https://github.com/gogf/gf/pull/4924) (@lingcoder)
- `oracle`: fix `GBK` decode and quoted identifiers. [#4836](https://github.com/gogf/gf/pull/4836) (@yuyinw); bring the driver up to the `MySQL` test baseline. [#4906](https://github.com/gogf/gf/pull/4906) (@lingcoder)
- `pgsql`: preserve `timetz` time zone offsets. [#4903](https://github.com/gogf/gf/pull/4903) (@014-code)
- `sqlite`: infer save conflict from primary keys. [#4766](https://github.com/gogf/gf/pull/4766) (@gqcn); exclude internal tables from `DAO` discovery. [#4908](https://github.com/gogf/gf/pull/4908) (@allenflux)

### Registry & config center `contrib`

- `nacos`: update `nacos-sdk-go` to `70993e7`. [#4888](https://github.com/gogf/gf/pull/4888) (@lingcoder)
- `registry/nacos`: add an `Option` pattern for registry configuration. [#4938](https://github.com/gogf/gf/pull/4938) (@ShryukGrandhi)
- `registry/zookeeper`: keep other instances when registering a service. [#4907](https://github.com/gogf/gf/pull/4907) (@taekop)

### ORM `database/gdb`

- Map database type names exactly in each driver instead of guessing from substrings. [#4882](https://github.com/gogf/gf/pull/4882) (@lingcoder)
- Preserve mixed values in undeclared columns. [#4905](https://github.com/gogf/gf/pull/4905) (@allenflux)
- Cache forced empty results. [#4919](https://github.com/gogf/gf/pull/4919) (@sean0407)
- Treat an empty `TxOptions.Propagation` as the default. [#4926](https://github.com/gogf/gf/pull/4926) (@somaz94)

### HTTP server `net/ghttp` / client `net/gclient`

- `gclient`: remove dead request body read in the tracing tracer. [#4900](https://github.com/gogf/gf/pull/4900) (@LanceAdd)
- `ghttp`: avoid a nil serving-handler panic on request struct parsing. [#4901](https://github.com/gogf/gf/pull/4901) (@LanceAdd); avoid a nil `serveHandler` panic on unmatched route parsing. [#4912](https://github.com/gogf/gf/pull/4912) (@LanceAdd)
- `ghttp`: strip the whole `:name` part when comparing router priority. [#4917](https://github.com/gogf/gf/pull/4917) (@LuisFigueroaG)
- `ghttp`: pin the default `Swagger UI` `Redoc` to `v2.5.3`. [#4922](https://github.com/gogf/gf/pull/4922) (@xuanwolei)
- `ghttp`: guard `preBindItems` against concurrent server starts. [#4927](https://github.com/gogf/gf/pull/4927) (@somaz94)
- `ghttp`: bind all values of repeated query keys to slice fields, like `PHP` does. [#4928](https://github.com/gogf/gf/pull/4928) (@LuisFigueroaG)
- `ghttp`/`goai`/`gtag`: replace `in:"body"` with `body:"*"` for the whole request body. [#4932](https://github.com/gogf/gf/pull/4932) (@LanceAdd)

### Other modules

- `cmd/gf`: reimplement `GoFmt` to avoid a `go env` subprocess per file. [#4929](https://github.com/gogf/gf/pull/4929) (@hailaz); avoid duplicate imports when ensuring an existing path. [#4945](https://github.com/gogf/gf/pull/4945) (@LanceAdd)

- `os/gsession`: publish atomic file snapshots on Unix. [#4910](https://github.com/gogf/gf/pull/4910) (@allenflux)
- `redis`: pin a dedicated connection in `Conn` for connection-stateful commands. [#4864](https://github.com/gogf/gf/pull/4864) (@yangfei1024)
- `text/gstr`: update `StrTill` to return the correct substring length and add unit tests. [#4873](https://github.com/gogf/gf/pull/4873) (@hailaz)
- `util/gconv`: preserve timezone when converting typed time values. [#4845](https://github.com/gogf/gf/pull/4845) (@hailaz)
- `util/grand`: keep the closed duration interval. [#4915](https://github.com/gogf/gf/pull/4915) (@salapenar-max)
- `util/gvalid`: measure a container by its element count in length rules. [#4865](https://github.com/gogf/gf/pull/4865) (@jiang-bx)

## Upgrade Guide

```bash
go get -u github.com/gogf/gf/v2@v2.10.4
```

Please upgrade the `CLI` to the corresponding version as well. If you use any of the following features, it is recommended to verify them first:

- `JSON` array request bodies and the `in:"body"` / `body:"*"` tags
- Dameng, `GaussDB`, `Oracle`, `MSSQL`, `PgSQL`, `SQLite`, and `ClickHouse` drivers
- `ORM` type mapping and default transaction propagation
- HTTP route priority and repeated query parameter binding
- `os/gcfg` file watchers and `os/gsession` snapshots
