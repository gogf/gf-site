## GoFrame v2.10.1 Released: Automatic i18n Loading, Config GetEffective, SHA512 and Database Fixes

`GoFrame v2.10.1` has been released. This version adds automatic `i18n` file decoding and loading by extension, the config `GetEffective` method and `SHA512` hashing, fixes issues in the `etcd` registry, `ORM` and `PgSQL` driver, and greatly expands test coverage for the `MySQL`, `MariaDB`, `PgSQL`, and `GaussDB` drivers.

Full changelog: [https://github.com/gogf/gf/releases/tag/v2.10.1](https://github.com/gogf/gf/releases/tag/v2.10.1)

Code diff: [https://github.com/gogf/gf/compare/v2.10.0...v2.10.1](https://github.com/gogf/gf/compare/v2.10.0...v2.10.1)

## New Features

### i18n `i18n/gi18n`

- Automatically detect the file extension and decode/load `i18n` file contents. [#4662](https://github.com/gogf/gf/pull/4662) (@The-night-elves)

### Configuration `os/gcfg`

- Added the `GetEffective` method, retrieving values by the standard config priority. [#4673](https://github.com/gogf/gf/pull/4673) (@lingcoder)

### Crypto `gcrypto/gsha512`

- Added a `SHA512` hash implementation. [#4667](https://github.com/gogf/gf/pull/4667) (@yuluo-yx)

### CLI `cmd/gf`

- `gen dao` added the `fileNameCase` option and AI coding content. [#4764](https://github.com/gogf/gf/pull/4764) (@gqcn)

## Bug Fixes

### Registry `contrib/registry`

- `etcd`: `etcd.NewWithClient()` no longer lacks `DialTimeout`. [#4670](https://github.com/gogf/gf/pull/4670) (@shengdoushi)
- `etcd`: `doKeepAlive` no longer fails to exit after the client context is done. [#4669](https://github.com/gogf/gf/pull/4669) (@yuluo-yx)

### ORM `database/gdb`

- Handle empty strings gracefully in `Fields()`. [#4700](https://github.com/gogf/gf/pull/4700) (@lingcoder)
- Treat negative `Limit` / `Page` / `Offset` values as zero. [#4702](https://github.com/gogf/gf/pull/4702) (@lingcoder)
- `AllAndCount` / `ScanAndCount` use `COUNT(1)` when the field count is greater than 1, even if `useFieldForCount` is true. [#4701](https://github.com/gogf/gf/pull/4701) (@lingcoder)
- Strip quote characters from the schema in `Model.TableFields`. [#4730](https://github.com/gogf/gf/pull/4730) (@lingcoder)

### Other Modules

- `os/gstructs`: strip tag options in `TagPriorityName` to avoid field name pollution. [#4681](https://github.com/gogf/gf/pull/4681) (@lingcoder)
- `contrib/drivers/pgsql`: preserve `bytea` data integrity on read and write. [#4678](https://github.com/gogf/gf/pull/4678) (@lingcoder)
- `contrib/drivers/mysql`: use an unreachable port for the `nodeInvalid` test config. [#4726](https://github.com/gogf/gf/pull/4726) (@lingcoder)
- Guard `os.Args` access for WASM builds to avoid a panic. [#4762](https://github.com/gogf/gf/pull/4762) (@gqcn)

## Upgrade Guide

```bash
go get -u github.com/gogf/gf/v2@v2.10.1
```

Please upgrade the `CLI` to the corresponding version as well. If you use any of the following features, it is recommended to verify them first:

- `i18n` file loading and `os/gcfg`'s `GetEffective`
- `gcrypto/gsha512` hashing
- `etcd` registry
- `ORM`'s `Fields()`, `Limit`/`Page`/`Offset`, and `AllAndCount`/`ScanAndCount`
- `PgSQL`'s `bytea` read/write

Questions and discussion: [https://github.com/gogf/gf/issues](https://github.com/gogf/gf/issues)
