# ORM Senior - UnmarshalValue

When we need to convert query results into custom types, whether as directly converted types or as attributes of a `struct`, we can achieve this by implementing specific interfaces. For detailed information, please refer to the [Type Conversion - Interface](https://goframe.org/en/docs/core/gconv-unmarshal-value.md) section.
