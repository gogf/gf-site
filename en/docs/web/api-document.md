# API Document

## Introduction

The `GoFrame` framework supports fully automated API documentation generation, ensuring that the code and API documentation are maintained synchronously. The automatically generated API documentation adopts the standard `OpenAPIv3` protocol. Before introducing the `OpenAPIv3` protocol, it is recommended that you first read and understand the framework's standardized routing features: [Standard Router](https://goframe.org/en/docs/web/router-registering-strict-router.md).
