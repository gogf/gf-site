Version: 2.10.x(Latest)

GoFrame v2.10.4 Released: JSON Array Bodies and HTTP Header Constants, with Comprehensive Fixes Across DM, GaussDB, Oracle and MSSQL Drivers​

GoFrame v2.10.4 has been released. This version mainly focuses on bug fixes, with an emphasis on improving compatibility and test coverage across database drivers (Dameng, GaussDB, Oracle, MSSQL, PgSQL, SQLite, ClickHouse, and more). It also adds JSON array request body support, HTTP header constants, and local coding-agent setup, along with several performance improvements.

Full changelog: https://github.com/gogf/gf/releases/tag/v2.10.4

Code diff: https://github.com/gogf/gf/compare/v2.10.3...v2.10.4

New Features​

CLI / Agents​

  • Added the gf-pr-create skill and refreshed the root README. #4878 (@gqcn)
  • agents: parallelize gf-pr-review and honor existing comments. #4879 (@gqcn)
  • agents: extend PR review and drop the openspec workflow. #4911 (@gqcn)
  • cmd/gf: added the gf agents command for local coding-agent setup. #4877 (@gqcn)

HTTP server net/ghttp / OpenAPI net/goai​

  • Support JSON array request bodies via the body:"*" field tag (initially introduced as in:"body" and renamed to body:"*" in this release). #4898 #4932 (@LanceAdd)
  • Added exported HTTP header name constants. #4899 (@LanceAdd)

Bug Fixes​

Database drivers contrib/drivers​

  • clickhouse: corrected conversion, inserts, and rewriting. #4916 (@lingcoder)
  • dm (Dameng): preserve quoted identifiers. #4828 (@yuyinw); ignore column name case when reading metadata columns. #4875 (@z312193608); apply timezone to the DM DSN. #4904 (@014-code); expand test coverage to the Oracle baseline with 18 driver fixes. #4925 (@lingcoder)
  • gaussdb: read int1[] and int16[] arrays back as arrays. #4896 (@lingcoder)
  • mssql: expand test coverage to the MySQL baseline with 16 driver fixes. #4924 (@lingcoder)
  • oracle: fix GBK decode and quoted identifiers. #4836 (@yuyinw); bring the driver up to the MySQL test baseline. #4906 (@lingcoder)
  • pgsql: preserve timetz time zone offsets. #4903 (@014-code)
  • sqlite: infer save conflict from primary keys. #4766 (@gqcn); exclude internal tables from DAO discovery. #4908 (@allenflux)

Registry & config center contrib​

  • nacos: update nacos-sdk-go to 70993e7. #4888 (@lingcoder)
  • registry/nacos: add an Option pattern for registry configuration. #4938 (@ShryukGrandhi)
  • registry/zookeeper: keep other instances when registering a service. #4907 (@taekop)

ORM database/gdb​

  • Map database type names exactly in each driver instead of guessing from substrings. #4882 (@lingcoder)
  • Preserve mixed values in undeclared columns. #4905 (@allenflux)
  • Cache forced empty results. #4919 (@sean0407)
  • Treat an empty TxOptions.Propagation as the default. #4926 (@somaz94)

HTTP server net/ghttp / client net/gclient​

  • gclient: remove dead request body read in the tracing tracer. #4900 (@LanceAdd)
  • ghttp: avoid a nil serving-handler panic on request struct parsing. #4901 (@LanceAdd); avoid a nil serveHandler panic on unmatched route parsing. #4912 (@LanceAdd)
  • ghttp: strip the whole :name part when comparing router priority. #4917 (@LuisFigueroaG)
  • ghttp: pin the default Swagger UI Redoc to v2.5.3. #4922 (@xuanwolei)
  • ghttp: guard preBindItems against concurrent server starts. #4927 (@somaz94)
  • ghttp: bind all values of repeated query keys to slice fields, like PHP does. #4928 (@LuisFigueroaG)
  • ghttp/goai/gtag: replace in:"body" with body:"*" for the whole request body. #4932 (@LanceAdd)

Other modules​

  • cmd/gf: reimplement GoFmt to avoid a go env subprocess per file. #4929 (@hailaz); avoid duplicate imports when ensuring an existing path. #4945 (@LanceAdd)
  • os/gcfg: recover file watchers after load errors. #4923 (@014-code)
  • os/gfpool: reopen a pooled file when its path points to another file. #4934 (@ShryukGrandhi)
  • os/gproc: restore default signal handling when shutdown listening. #4868 (@jiang-bx)
  • os/gsession: publish atomic file snapshots on Unix. #4910 (@allenflux)
  • redis: pin a dedicated connection in Conn for connection-stateful commands. #4864 (@yangfei1024)
  • text/gstr: update StrTill to return the correct substring length and add unit tests. #4873 (@hailaz)
  • util/gconv: preserve timezone when converting typed time values. #4845 (@hailaz)
  • util/grand: keep the closed duration interval. #4915 (@salapenar-max)
  • util/gvalid: measure a container by its element count in length rules. #4865 (@jiang-bx)

Performance​

  • internal/instance, i18n/gi18n, os/gcfg, database/gdb: check the cached instance with a reading lock. #4902 (@LanceAdd)
  • net/ghttp: skip unused request tag handling. #4889 (@LanceAdd)
  • util/gvalid: speed up struct validation. #4886 (@LanceAdd)

Refactor​

  • Use constants across multiple modules. #4931 (@LanceAdd)
  • net/gclient: split prepareRequest into focused helper functions. #4890 (@LanceAdd)

Tests​

  • Expanded test coverage to the MySQL baseline for several drivers: oceanbase. #4894, sqlite. #4892 (+2 driver fixes), sqlitecgo. #4897 (+3 driver fixes), tidb. #4893 (@lingcoder)
  • sqlite test detail fixes: take the colon of the path from the drive letter on Windows. #4885; assert Test_DB_Ctx timeout via the context instead of the error text. #4918 (@lingcoder)

Upgrade Guide​

go get -u github.com/gogf/gf/v2@v2.10.4

Please upgrade the CLI to the corresponding version as well. If you use any of the following features, it is recommended to verify them first:

  • JSON array request bodies and the body:"*" tag
  • Dameng, GaussDB, Oracle, MSSQL, PgSQL, SQLite, and ClickHouse drivers
  • ORM type mapping and default transaction propagation
  • HTTP route priority and repeated query parameter binding
  • os/gcfg file watchers and os/gsession snapshots

Questions and discussion: https://github.com/gogf/gf/issues
