:::warning 废弃提示
从版本`v2.10.0`开始，`gpage`组件已被标记为**废弃**，将在未来版本中被移除。

**推荐替代方案**：
1. **使用ORM分页功能**：`GoFrame`的`gdb` `ORM`组件提供了完善的分页支持。
2. **自定义分页逻辑**：根据业务需求实现分页，前端使用现代化的`UI`组件库。
3. **API分页**：返回分页数据结构，由前端框架处理分页显示。
:::

分页管理由 `gpage` 模块实现，具体请参考 [分页管理](../../WEB服务开发/分页管理/分页管理.md) 章节。
