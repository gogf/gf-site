## GoFrame v2.10.6 发布：新增 `ghttp` 请求体自动解码开关与 `grpcx` 服务端超时，加固解压与静态文件安全，修复 `gdb`、`gtime`、`gcompress` 等模块问题

`GoFrame v2.10.6` 已发布。本版本新增 `ghttp.Server` 的 `AutoDecodingBodyDisabled` 配置和 `contrib/rpc/grpcx` 一元请求的服务端超时控制；重点修复了 `encoding/gcompress` 的 `zip` 解压路径穿越、`net/ghttp` 与 `os/gspath` 的目录越界读取、`database/gdb` 分区查询、`os/gtime` 跨夏令时时区偏移与时间戳溢出等问题，同时补充了大量单元测试并完成一轮现代化重构。

完整变更：[https://github.com/gogf/gf/releases/tag/v2.10.6](https://github.com/gogf/gf/releases/tag/v2.10.6)

代码差异：[https://github.com/gogf/gf/compare/v2.10.5...v2.10.6](https://github.com/gogf/gf/compare/v2.10.5...v2.10.6)

---

## 新功能

### HTTP 服务 `net/ghttp`

- 新增 `AutoDecodingBodyDisabled` 配置，可以按需关闭请求体的自动解码。[#4197](https://github.com/gogf/gf/pull/4197)（@gqcn）

### RPC 服务 `contrib/rpc/grpcx`

- 为一元请求新增服务端超时控制。[#4996](https://github.com/gogf/gf/pull/4996)（@officialasishkumar）

---

## 问题修复

### HTTP 服务 `net/ghttp`

- 静态文件读取锚定在搜索根目录内，避免越界读取。（Security）[#4985](https://github.com/gogf/gf/pull/4985)（@LanceAdd）
- 静态目录列表的链接做转义处理，避免页面注入。（Security）[#5009](https://github.com/gogf/gf/pull/5009)（@LanceAdd）
- 使用 `net.SplitHostPort` 解析监听地址的 `host` 与端口。[#5007](https://github.com/gogf/gf/pull/5007)（@LanceAdd）

### HTTP 客户端 `net/gclient`

- 保留 `URL` 片段（fragment）之前的查询参数。[#5025](https://github.com/gogf/gf/pull/5025)（@LanceAdd）

### 压缩编码 `encoding/gcompress`

- 阻止 `zip` 解压时的路径穿越。（Security）[#5010](https://github.com/gogf/gf/pull/5010)（@LanceAdd）
- 解压结束后关闭读取器，避免文件句柄泄漏。[#5013](https://github.com/gogf/gf/pull/5013)（@LanceAdd）

### JSON 编码 `encoding/gjson`

- 拒绝负数数组下标，且不再产生部分写入。[#5012](https://github.com/gogf/gf/pull/5012)（@LanceAdd）

### 其他编码组件

- `encoding/gini`：正确解析没有结尾换行的最后一行配置。[#5014](https://github.com/gogf/gf/pull/5014)（@LanceAdd）
- `encoding/gbinary`：`EncodeBitsToBytes` 不再修改调用方传入的切片。[#5011](https://github.com/gogf/gf/pull/5011)（@LanceAdd）
- `encoding/gurl`：`RawDecode` 保留字面加号。[#5016](https://github.com/gogf/gf/pull/5016)（@LanceAdd）

### ORM `database/gdb`

- `SELECT` 查询输出 `Model.Partition()` 设置的 `PARTITION` 子句。[#4976](https://github.com/gogf/gf/pull/4976)（@lingcoder）

### 时间 `os/gtime`

- `StrToTime` 跨夏令时时不再丢失时区偏移。[#4995](https://github.com/gogf/gf/pull/4995)（@ruziba3vich）
- 修复 `Timestamp` 在 `UnixNano` 范围之外溢出。[#4989](https://github.com/gogf/gf/pull/4989)（@ruziba3vich）
- 与 `os/gcron`、`internal/tracing` 一起改用 Unix 时间辅助函数。[#5005](https://github.com/gogf/gf/pull/5005)（@LanceAdd）

### 定时任务 `os/gcron`

- 间隔小于 `1` 的表达式直接报错，不再无限循环。[#5019](https://github.com/gogf/gf/pull/5019)（@ruziba3vich）

### 文件与路径 `os/gfile`、`os/gspath`

- `os/gfile`：`ReadLines` 不再丢弃超长行。[#5024](https://github.com/gogf/gf/pull/5024)（@LanceAdd）
- `os/gspath`：路径搜索结果保持在搜索根目录内。（Security）[#5023](https://github.com/gogf/gf/pull/5023)（@LanceAdd）

### 网络工具 `net/gipv4`、`net/gtrace`

- `net/gipv4`：使用 `netip` 判断内网地址。[#5006](https://github.com/gogf/gf/pull/5006)（@LanceAdd）
- `net/gipv4`：修复 `Ip2long` 处理 `IPv6` 地址时的 `panic`。[#4990](https://github.com/gogf/gf/pull/4990)（@ruziba3vich）
- `net/gtrace`：大小写不敏感地识别 `gzip` 内容编码。[#5026](https://github.com/gogf/gf/pull/5026)（@LanceAdd）

### 工具函数 `util/gutil`

- 改为比较类型化取值，不再用相减判断大小。[#5004](https://github.com/gogf/gf/pull/5004)（@LanceAdd）
- 修复整数比较器在溢出时返回错误符号。[#4994](https://github.com/gogf/gf/pull/4994)（@ruziba3vich）

### 字符串 `text/gstr`

- 字符串长度恰好等于限制值时不再重复追加后缀。[#4993](https://github.com/gogf/gf/pull/4993)（@ruziba3vich）
- `TrimLeftStr`、`TrimRightStr` 在切分串为空时不再死循环。[#4991](https://github.com/gogf/gf/pull/4991)（@ruziba3vich）
- 修正 `Str` 在查找串长度大于一个字节时的返回结果。[#4992](https://github.com/gogf/gf/pull/4992)（@ruziba3vich）

### 数组 `container/garray`

- `Range` 支持文档约定的负数结束下标。[#5020](https://github.com/gogf/gf/pull/5020)（@ruziba3vich）

### 开发工具 `cmd/gf`

- `gen ctrl` 识别带参数的 `NewV1` 构造器，避免重复生成 `ControllerV1`。[#4980](https://github.com/gogf/gf/pull/4980)（@Lizjunn）
- 恢复基于 `imports.Process` 的 `GoFmt` 处理。[#5045](https://github.com/gogf/gf/pull/5045)（@hailaz）

### 社区组件 `contrib/rpc/grpcx`

- 为监听器加互斥锁，修复数据竞争。[#5046](https://github.com/gogf/gf/pull/5046)（@hailaz）
- `Serve` 返回 `grpc.ErrServerStopped` 时不再退出进程。[#5049](https://github.com/gogf/gf/pull/5049)（@LanceAdd）

## 代码重构

- `container/gset`、`container/gmap`、`util/gutil` 改用 `maps` 与 `slices` 辅助函数。[#4999](https://github.com/gogf/gf/pull/4999)（@LanceAdd）
- `container/garray`、`text/gstr`、`os/gcmd` 改用 `slices` 辅助函数。[#5000](https://github.com/gogf/gf/pull/5000)（@LanceAdd）
- 容器、`database/gdb`、`encoding`、`net`、`os`、`cmd/gf` 的排序逻辑改用 `slices`。[#4997](https://github.com/gogf/gf/pull/4997)（@LanceAdd）
- `encoding` 下多个模块改用标准库等价实现。[#5015](https://github.com/gogf/gf/pull/5015)（@LanceAdd）
- `encoding`、`net`、`os`、`text/gstr`、`util/gvalid`、`internal/httputil` 改用 `strings.Cut` 等标准辅助函数。[#4998](https://github.com/gogf/gf/pull/4998)（@LanceAdd）
- `encoding/gjson` 移除失效的嵌套数组扩展循环。[#5017](https://github.com/gogf/gf/pull/5017)（@LanceAdd）
- `container/gmap` 移除过时的 `go1.24` 构建标签。[#5003](https://github.com/gogf/gf/pull/5003)（@LanceAdd）

## 升级建议

```bash
go get -v github.com/gogf/gf/v2@v2.10.6
```

本版本为修正版本，保持向后兼容。若你用到以下能力，建议优先验证：

- `ghttp` 静态文件服务与请求体自动解码行为
- `gcompress` 的 `zip` 解压路径校验
- `gdb` 分区表查询
- `gtime` 的时区与时间戳转换
- `garray.Range`、`gstr` 的字符串截断与裁剪

问题与讨论：[https://github.com/gogf/gf/issues](https://github.com/gogf/gf/issues)

欢迎 `Star`、提 `Issue` 和 `PR`。`GoFrame`，让 Go 开发更简单。
